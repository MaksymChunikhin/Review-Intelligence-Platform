# Portfolio Metrics

This directory contains compact aggregate metrics suitable for the public
source repository. It intentionally excludes raw reviews, user identifiers,
full model binaries, manual-review queues, and generated seller workbooks.

The values in `project_metrics.json` are copied from the validated local
dataset, niche population, model-evaluation, and aspect-population reports.
They describe the fixed 2021-01-01 through 2023-09-13 historical snapshot.
